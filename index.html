麻醉後照護 POST-ANESTHESIA CARE GUIDE
術後照護
THEME 05 · 麻醉衛教
手術後，安心恢復
從這裡開始
回到病房的第一天最關鍵。飲食、活動、傷口、用藥——每個環節都影響恢復速度。本指引幫助您與家屬了解術後照護的重點，讓恢復更順利、更安心。
🍵 飲食恢復
🍵
循序漸進，腸胃慢慢甦醒
依醫護人員指示開始，不要急著進食
1
術後初期——禁食或清流質
手術後腸胃功能尚未完全恢復，需等醫護評估後才可飲水。開始時以少量溫水或清流質（米湯、清湯）為主。
2
腸胃排氣後——軟食
當您開始排氣（放屁）表示腸胃蠕動恢復，可進階為粥、豆腐等軟質食物。
3
恢復正常——一般飲食
依醫囑逐步恢復正常飲食。術後應補充蛋白質（魚、豆腐、蛋）幫助傷口癒合，避免辛辣刺激食物。
🚶 活動與休息
🚶
早期下床，減少併發症
臥床太久反而不利恢復
💡 早期活動能促進腸胃蠕動、預防血栓、改善肺功能——只要醫師同意，越早下床越好！
✓
臥床時每小時做腳踝轉動、腿部伸展，促進下肢血液循環
✓
第一次下床一定要有護理師或家屬陪同，避免跌倒
✓
起身時先在床邊坐穩再站立，適應幾分鐘再行走
✓
每天逐漸增加活動量，但感到疲倦或頭暈時立刻休息
✓
依醫囑做深呼吸及咳嗽運動，預防肺炎
🩹 傷口照護
💧
保持乾燥
傷口敷料保持乾燥，淋浴時用防水貼膜保護，依醫囑決定何時可淋浴
👀
每日觀察
每天檢查傷口顏色、腫脹、分泌物，有異常立即告知護理師
🚫
不自行撕除
不要自行撕除敷料或縫線，換藥時間與方式依醫護指示
🧴
避免刺激
傷口癒合期間避免泡澡、泡湯、游泳，避免塗抹未經醫師同意的藥膏
⚠️ 出現以下情況請告知醫護人員
傷口紅腫、熱痛明顯加重
傷口滲出大量液體或有異味
傷口裂開或縫線脫落
發燒超過 38°C
💊 用藥注意
💊
止痛藥與術後用藥
疼痛不需要忍耐，按時用藥才能早日恢復
✓
依護理師指示按時服用止痛藥，不要等到非常痛才吃
✓
若有使用自控式止痛（PCA），感覺疼痛就可以按鈕，不用擔心過量
✓
術前原本在服用的慢性病藥物，何時恢復服用請詢問醫師
✓
出院時確認帶走所有醫師開立的藥物，並了解服藥方式
🏠 出院後注意事項
🏠
回家後的重要提醒
出院不代表完全恢復，仍需持續觀察
✓
術後 24 小時內不可開車、操作機械或從事需高度專注的活動
✓
避免飲酒——酒精與麻醉藥殘餘作用相互影響
✓
依醫師指示回門診複查，不要自行停藥或延誤回診
✓
家屬應陪同在旁，觀察患者狀態變化
✓
休養期間保持室內通風，適當休息，避免過度勞累
🚨 出現以下情況請立即就醫或撥打 119
呼吸困難、胸悶、胸痛
意識不清、無法喚醒
大量出血或血壓極低（頭暈、昏厥）
嚴重嘔吐無法進水超過 8 小時
下肢單側明顯腫脹、疼痛（可能血栓）
高燒超過 39°C 且持續不退
恢復是一個過程，不要給自己太大壓力。
